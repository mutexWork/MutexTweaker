# MutexTweaker

Тонкая настройка Windows 10/11: сеть, питание, службы, приватность, Проводник, ввод,
хранилище и задержки. Тёмный минималистичный интерфейс, всё в одном окне.

## ⬇️ Установка в два клика

1. Скачайте **[MutexTweaker_Setup.exe](MutexTweaker_Setup.exe?raw=true)** (кнопка **Download** на странице файла).
2. Запустите файл → **Да** в запросе UAC → **Установить**.

Готово: ярлык появится в меню «Пуск» и на рабочем столе.

> **Ничего доустанавливать не нужно.** Не требуются Visual C++ Redistributable, .NET
> и права «запуск от имени администратора» вручную — программа сама запросит повышение прав.
> Бинарники не импортируют `MSVCP140*.dll` / `VCRUNTIME140*.dll` / `ucrtbase*.dll`.

## Главное

- **26 рабочих твиков** — каждый проверен на реальной системе, состояние восстанавливается.
- **Точка восстановления** создаётся по умолчанию перед применением твиков. Галочка
  «Сделать точку восстановления» внизу окна позволяет её отключить. Если точка не создана
  или создать её не удалось, программа спросит, продолжать ли (по умолчанию — «Нет»).
- **Схема «Максимальная производительность»** активируется через `powercfg` (создаётся, если её нет).
- **Информация о системе**: процессор, видеокарта, объём, тип и частота ОЗУ.
- Кнопки «Выбрать все», «Снять все», «Применить выбранное», «Применить всё».
- Предупреждение о перезагрузке, если выбранные твики требуют её.

## Твики

| ID | Название | Что делает |
|----|----------|------------|
| `net_tcp_nagle` | Отключить алгоритм Nagle | `TcpAckFrequency` / `TCPNoDelay` = 1 для всех интерфейсов |
| `net_dns_flush` | Сбросить DNS-кэш | `ipconfig /flushdns` |
| `net_throttling` | Снять ограничение сети | `NetworkThrottlingIndex` = 0xFFFFFFFF |
| `net_delivery_opt` | Отключить P2P-обновления | `DODownloadMode` = 0, политика + конфиг |
| `pow_highperf` | Схема «Высокая производительность» | `powercfg /setactive` |
| `pow_ultimate` | Схема «Максимальная производительность» | создаёт и включает Ultimate Performance |
| `svc_sysmain` | Отключить службу SysMain | `Start` = 4, остановка службы |
| `svc_diagtrack` | Отключить телеметрию | `DiagTrack` → Disabled |
| `svc_wer` | Отключить отчёты об ошибках | `WerSvc` + `Disabled` в HKLM/HKCU |
| `priv_telemetry_light` | Ограничить телеметрию | `AllowTelemetry` = 0 |
| `priv_gamedvr` | Отключить Xbox Game DVR | запись и политика |
| `priv_ads` | Убрать рекламу и подсказки | `ContentDeliveryManager`, рекламный ID |
| `priv_cortana` | Отключить Cortana и веб-поиск | политики поиска + `BingSearchEnabled` |
| `priv_activity` | Отключить журнал действий | `EnableActivityFeed` и др. |
| `priv_feedback` | Отключить запросы отзывов | `DoNotShowFeedbackNotifications`, SIUF |
| `exp_ext` | Показывать расширения файлов | `HideFileExt` = 0 |
| `exp_hidden` | Показывать скрытые файлы | `Hidden` / `ShowSuperHidden` = 1 |
| `exp_launch` | Открывать «Этот компьютер» | `LaunchTo` = 1 |
| `exp_restart_apps` | Не восстанавливать приложения | `RestartApps` = 0 |
| `inp_mouse` | Ускорить наведение мыши | `MouseHoverTime` = 100 |
| `inp_keyboard` | Уменьшить задержку клавиатуры | `KeyboardDelay` = 0 |
| `inp_mouse_accel` | Отключить ускорение мыши | `MouseSpeed` / пороги = 0 |
| `stor_temp_user` | Очистить `%TEMP%` | удаление файлов пользователя |
| `stor_system_temp` | Очистить системный Temp | `C:\Windows\Temp` |
| `stor_hibernate_off` | Отключить гибернацию | `powercfg /h off` |
| `lat_mmcss` | Приоритет игр MMCSS | `SystemResponsiveness` = 0, GPU/Priority игр |

## Безопасность и откат

- По умолчанию перед применением создаётся точка восстановления Windows
  (при необходимости включается защита системы на диске `C:`).
- Все изменения — стандартные параметры реестра, служб и `powercfg`; ничего не «патчится»
  в системных файлах.
- Удаление: «Параметры → Приложения» или ярлык деинсталляции в меню «Пуск».
- Откат твиков: «Восстановление системы» → выберите точку, созданную MutexTweaker.

## Требования

- Windows 10 или Windows 11, x64.
- Права администратора (запрашиваются автоматически).
- Интернет не нужен.

## Сборка из исходников

Нужны Visual Studio 2022 (Desktop development with C++), CMake и — для установщика — Inno Setup 6.

```bat
build.bat
```

Скрипт собирает ядро (`core`), GUI (`gui`) и установщик.
Результат: `gui\Output\MutexTweaker_Setup.exe`.

По отдельности:

```bat
core\build_core.bat     :: core\build\bin\MutexTweaker.dll
gui\build_gui.bat       :: gui\build\bin\MutexTweakerGUI.exe + DLL
```

Установщик можно пересобрать отдельно:

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" gui\build_installer.iss
```

Исходники GUI хранятся в UTF-8; в `build_gui.bat` уже включён флаг `/utf-8`.

## Структура репозитория

```
MutexTweaker_Setup.exe   готовый установщик 1.0.1 (то, что скачивают пользователи)
build.bat                полная сборка: ядро → GUI → установщик
core\                    ядро на C++: твики, система, точка восстановления (DLL + C API)
gui\                     интерфейс WinAPI + GDI+, установщик Inno Setup
```
