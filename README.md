# MutexTweaker

Тонкая настройка Windows с тёмным минималистичным интерфейсом.

![Интерфейс MutexTweaker](screenshot.png)

## Возможности

- 26 рабочих твиков: сеть, питание, службы, приватность, Проводник, ввод, хранилище, задержки.
- План электропитания: создаёт и включает **«Максимальная производительность»** (Ultimate Performance)
  через `powercfg`, с откатом на «Высокую производительность» только если схему создать нельзя.
- Блок конфигурации: процессор, видеокарта, объём/тип/частота ОЗУ.
- Кнопки «Выбрать все», «Снять все», «Применить всё» и «Применить выбранное».
- Запрос прав администратора при запуске, предупреждение о перезагрузке.
- Тёмная тема GDI+, аккуратные карточки, кастомные кнопки и шапка списка.
- Окно открывается развёрнутым на весь экран.

## Список твиков

| ID | Название |
|----|----------|
| `net_tcp_nagle` | Отключить алгоритм Nagle |
| `net_dns_flush` | Сбросить DNS-кэш |
| `net_throttling` | Снять ограничение сети |
| `net_delivery_opt` | Отключить P2P-обновления |
| `pow_highperf` | Схема «Высокая производительность» |
| `pow_ultimate` | Схема «Максимальная производительность» |
| `svc_sysmain` | Отключить службу SysMain |
| `svc_diagtrack` | Отключить службу телеметрии |
| `svc_wer` | Отключить отчёты об ошибках |
| `priv_telemetry_light` | Ограничить телеметрию |
| `priv_gamedvr` | Отключить Xbox Game DVR |
| `priv_ads` | Убрать рекламу и подсказки |
| `priv_cortana` | Отключить Cortana и веб-поиск |
| `priv_activity` | Отключить журнал действий |
| `priv_feedback` | Отключить запросы отзывов |
| `exp_ext` | Показывать расширения файлов |
| `exp_hidden` | Показывать скрытые файлы |
| `exp_launch` | Открывать «Этот компьютер» |
| `exp_restart_apps` | Не восстанавливать приложения |
| `inp_mouse` | Ускорить наведение мыши |
| `inp_keyboard` | Уменьшить задержку клавиатуры |
| `inp_mouse_accel` | Отключить ускорение мыши |
| `stor_temp_user` | Очистить папку %TEMP% |
| `stor_hibernate_off` | Отключить гибернацию |
| `stor_system_temp` | Очистить системный Temp |
| `lat_mmcss` | Приоритет игр MMCSS |

## Сборка

Ядро (DLL + LIB):

```bat
cd /d C:\MTSrc
build_core.bat
```

GUI:

```bat
cd /d C:\MutexTweakerGUI
build_gui.bat
```

Результат: `build\bin\MutexTweakerGUI.exe` и `build\bin\MutexTweaker.dll`.

## Установщик

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build_installer.iss
```

Результат: `Output\MutexTweaker_Setup.exe`.

Установка в `C:\Program Files\MutexTweaker`, ярлыки в меню «Пуск» и на рабочем столе,
запись в «Установка и удаление программ», удаление файлов при деинсталляции.

## Требования

- Windows 10/11 x64.
- Права администратора (приложение запрашивает их через манифест).
